# 🏙️ 3D 都市漫遊

**線上玩:https://hfpc-city3d.summer09201017.workers.dev**

沒有比賽、沒有名次。挑一種載具,在都市裡想去哪就去哪。

- 🚶 **人行道、廣場、公園全都開得上去** —— 地面只決定快慢,沒有一種是牆。
- 🧒 **撞不傷人** —— 行人會先閃開,真的碰到只是被推開、車子掉速。
- 🐎 **五種載具隨時換**(數字鍵 1~5,開到一半也能換):賽車、摩托車、馬、跑步、懸浮車。
  馬、跑步、懸浮車草地零減速,可以直接穿過公園抄近路。
- 👶 **年齡三檔**(幼幼 / 兒童 / 青少),跨站共用偏好;幼幼檔會自動唸玩法給還不識字的孩子。
- 📷 五檔視角,含駕駛座第一人稱。

## 操作

| 動作 | 鍵盤 | 手把 |
|---|---|---|
| 油門 / 煞車 | ↑ / ↓ | 扳機 |
| 轉彎 | ← → | 左類比 |
| 渦輪 | Shift | A |
| 手煞(甩尾送加速) | 空白鍵 | B |
| 換視角 | V | Y |
| 換載具 | 1~5 | — |

## 開發

```bash
npm install
npm run dev          # 本機開發
npm test             # 42 項 node 測試(不需瀏覽器)
npm run build
npm run check:local  # 41 項真瀏覽器驗收
npm run voice        # 重烤人聲 mp3(累加式,已有的跳過)
```
